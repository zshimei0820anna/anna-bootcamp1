# Health Informatics & Precision Medicine Project Portfolio

This repository contains selected reproducible projects, exploratory analysis notebooks, and mini-projects related to health informatics, biomedical data analytics, clinical data analysis, and precision medicine.

The purpose of this repository is to document project-based work rather than a private learning plan. Each project is organized with code, notebooks, outputs, and a short interpretation summary when available.

## Focus Areas

- Health data cleaning and exploratory data analysis
- Biomedical tabular data analysis
- SQL-based clinical data querying
- Regression modeling and model evaluation
- Survival analysis
- Precision medicine and oncology informatics
- Simplified reproduction of published analysis workflows
- Reproducible research using Python, R, SQL, and Jupyter Notebook
